rustupaint UEFI Shell 上的小画家

一个运行在 UEFI Shell 里的画图程序：逻辑用 Rust 编写，界面与渲染交给 LVGL 9.2.2，由 EDK2 负责把它链接成一个 UEFI 应用。没有操作系统， 没有窗口管理器 —— 从固件直接进入画布。

1. 运行与启动

把 rustupaint.efi 放进一个 FAT 分区，在 UEFI Shell 下直接执行即可。

项目说明
运行环境UEFI Shell（x86_64），需要 GOP 图形输出与一个指针设备
指针设备USB 鼠标（boot 协议即可）；PS/2 与 usb-tablet 不可用
推荐分辨率1280 × 800（本手册截图即此分辨率，画布 1208 × 648）
最小分辨率320 × 240，低于此值会拒绝启动并打印原因
依赖无。字库已内建，镜像约 1.4 MB
在 QEMU 下试玩：用仓库里的 tools\Run-RustPaintQemu.ps1 -Interactive 启动， 会弹出一个可交互的 SDL 窗口。鼠标点进窗口后按 左 Ctrl + 左 Alt 可以把指针释放回宿主机。

2. 界面总览

整个界面自上而下分成五个区域，全部中文化，配色沿用 Win11 的浅色观感。

区域内容
标题栏应用名、当前画布尺寸、右上角作者署名
菜单栏文件、编辑、帮助
工具栏八个工具按钮（纯图标，鼠标悬停出提示）
画布实际作画区域，带 1px 描边与淡投影
底部调色板（当前色预览 + 16 个色块）与状态栏

3. 工具栏（八个工具）

左侧工具条是纯图标的。图标再象形也不如一行字明确，所以鼠标在按钮上 停留约 0.4 秒，右边就会浮出一个提示框，写明工具名和一句用法。 下面八张图就是实际悬停时的画面。

「清空」不是持续工具。点它就执行一次，然后自动回到你之前用的工具 —— 否则每次清空后都要手动切回去，很烦。

4. 调色板

底部一行 16 个色块，最左边的大方块是当前色预览。点任意色块即切换当前色， 铅笔、直线、矩形、椭圆、填充都用它。浅色块（白、浅灰）带 1px 描边， 否则在浅色底上会「消失」。

顺序颜色
第 1–4 个黑、灰、浅灰、白
第 5–8 个深红、红、橙、黄
第 9–12 个绿、蓝绿、青、蓝
第 13–16 个靛、紫、品红、棕

5. 绘图操作

八种工具的用法可以归成三类：点一下（填充、取色、清空）、 按住拖动（铅笔、橡皮、直线、矩形、椭圆）。 下面逐帧演示一遍完整的作画过程。

5.1 铅笔：选色后自由手绘

先在调色板点红色，再按住左键在画布上拖动，画出自由曲线。

5.2 直线：按住拖动画一条直线

换蓝色，选直线工具，从起点拖到终点松手。

5.3 矩形：拖出空心边框

5.4 椭圆：拖出外接矩形即得椭圆

5.5 填充：点一下填满同色区域

换成橙色，选填充工具，在刚才的矩形内部点一下 —— 矩形内腔被整片填满。

5.6 取色：把画布上的颜色「吸」过来

选取色工具，在填好的橙色区域点一下。注意底部：当前色预览和状态栏的颜色都已变成橙色。

5.7 撤销

「编辑」菜单里的撤销，可以回退最近一次绘制动作。

关于性能：填充是逐像素扫描线算法，在 QEMU 这种无加速的虚拟显卡上， 填充很大面积（接近整块画布）会看到明显的卡顿。真机上受限于 GOP 的逐像素拷贝， 同样会慢，只是幅度小些。小区域填充没有感知。

6. 菜单

菜单栏三个菜单，点标题展开、再点一次收起；点菜单以外的任何地方也会收起。

菜单菜单项作用
文件新建清空画布，重新开始
退出退出程序，返回 UEFI Shell
编辑撤销回退最近一次绘制
清空清空整幅画布
帮助关于版本、作者与快捷键说明

7. 键盘与焦点

除了鼠标，整个界面也能用键盘操作。Tab 在控件之间 移动焦点，获得焦点的控件会显示蓝色强调色的焦点圈；按 Enter 等同于点它。

按键作用
Tab焦点移到下一个控件（菜单 → 工具 → 色块）
Shift + Tab焦点反向移动
Enter激活当前焦点控件
Esc关闭已展开的菜单或对话框

8. 状态栏

从左到右分别是：

字段含义
工具当前选中的工具名，切换工具即时更新
颜色当前色，十六进制 #RRGGBB；取色后同步变化
位置光标在画布像素坐标系里的位置（画布左上角为 0,0）
画布画布像素尺寸
版本版本号 + 构建时间戳
指针移出画布时，坐标会退回 x -, y -，而不是冻在最后一个值上 —— 否则状态栏会显示一个「光标早就不在那儿」的陈旧坐标。

12. 已知限制

诚实列一下当前版本还做不到的事，避免误解：

限制说明
不能保存 / 打开文件尚未接入 UEFI 的文件系统读写，退出即丢失
撤销深度固定 8 层每层保存整幅画布快照，大画布下内存占用可观
油漆桶大区域偏慢逐像素扫描线填充，QEMU 下填满整屏会有可见卡顿
标题栏没有窗口按钮最小化 / 最大化 / 关闭未实现（UEFI 下无窗口管理器，属装饰性）
没有悬停变色LVGL 9 无原生 hover 状态；交互反馈由按下态与焦点态承担，悬停只出提示框

本轮修复记录（0.1.0.24）

问题根因与修复
工具栏图标看不懂是什么功能 新增悬浮提示：每拍轮询指针位置做命中判定，停留 0.4 秒后浮出工具名与用法
笔迹相对光标偏左约 56px 画布定位漏加工具栏宽度：rp_set_pos 少传了 area_x， 画布实际画在屏幕 x=8，而坐标换算仍按 x=64。现两处共用同一个 cv_x， 结构上无法再分叉
状态栏坐标始终是「- -」 rp_mouse_pos 取点用了 lv_indev_active()， 在键鼠双 indev 工程里会指到键盘上、类型检查失败后直接返回 0。 改为直接问鼠标 indev
